### Algorithm
1. Parse net_amounts (YYYYMMDD → cumulative float).
2. Calculate deltas between consecutive entries.
3. Skip first entry if 0.0 (account open marker).
4. Skip zero deltas.
5. Determine type: positive → "contribution", negative → "withdrawal".
6. Round amounts to 2 decimals.
7. Multi-account: sum deltas by date, discard per-account cumulatives, recalculate running total.

### Caching
Events serialized in 24h portfolio JSON cache (investment_portfolio_cache.payload) via dataclasses.asdict(). No database migration required.
